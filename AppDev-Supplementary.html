AppDev Supplementary Exam Practice

80 one-line coding questions on JavaScript, CSS, and ReactJS. Questions 1–10 are from the instructor. Questions 11–80 are for extra practice. Treat each item independently and assume referenced variables and components already exist.

Use the exact names, capitalization, brackets, and semicolons shown in the model answers. The checker accepts common formatting variations and straight single or double quotes where both work. Compare any other valid version with the model answer.

Instructor questions 1–10

JavaScript

1. Write the statement that declares a variable named myName with the value "Alice" using let.

let myName = "Alice";

let declares a variable that can be reassigned. Use straight quotes around the string. (JS exercise 1)

JavaScript

2. Write the statement that creates an object named aboutMe with name set to "Alice" and age set to 20.

const aboutMe = { name: "Alice", age: 20 };

An object literal uses braces, colons between keys and values, and commas between properties. Only the name value is a string. (JS exercise 4)

JavaScript

3. Write the for loop that logs the numbers 1 to 5 using the variable i.

for (let i = 1; i <= 5; i++) { console.log(i); }

The condition includes 5. The update i++ adds one after each iteration. (JS exercise 6)

JavaScript

4. Write an arrow function named greet that takes name and returns "Hello, " + name using an implicit return.

const greet = name => "Hello, " + name;

An arrow function with a single expression after => returns that expression automatically. Keep the trailing space inside the greeting string. (JS exercise 11)

JavaScript

5. Write the statement that creates liked by using .map() on favoriteFoods to turn each food into "I like " + food.

const liked = favoriteFoods.map(food => "I like " + food);

.map() produces a new array from the callback’s return value. The space after like separates it from the food name. (JS exercise 5)

CSS

6. Write the ruleset for the class title that sets the font size to 32px.

.title { font-size: 32px; }

The leading dot selects an element with the class title. The px unit is attached directly to 32. (React exercise 18)

CSS

7. Write the ruleset for :root that defines a CSS variable named --color-primary with the value #5b86e5.

:root { --color-primary: #5b86e5; }

:root defines a custom property that styles elsewhere can read. Custom property names start with --. (CSS slide 5)

ReactJS

8. Write the statement that imports the default export Title from ./components/Title.

import Title from "./components/Title";

A default import names the local binding directly. The quoted relative path starts with ./. (React exercise 2)

ReactJS

9. Write the JSX paragraph that shows ©, then the variable year, then the text Anong WISH mo?.

<p>© {year} Anong WISH mo?</p>

JSX braces evaluate year. The copyright symbol and the words around the expression are rendered as text. (React exercise 12)

ReactJS

10. Write the <h1> element with the text Wish 107.5 Playlist and the class title applied using className.

<h1 className="title">Wish 107.5 Playlist</h1>

React uses className to assign a CSS class in JSX. A literal class name goes in quotes. (React exercise 18)

JavaScript

if (score >= 70) { console.log("Pass"); } else { console.log("Fail"); }

JavaScript

while (count < 3) { console.log("Hello"); count++; }

The condition is checked before each iteration. Incrementing count after logging makes the loop run for counts 0, 1, and 2. (JS exercise 6)

JavaScript

JavaScript

27. Declare sum(...args) as a regular function that returns args.reduce() with (total, n) => total + n and an initial value of 0.

function sum(...args) { return args.reduce((total, n) => total + n, 0); }

The rest parameter collects arguments into args. reduce() starts at 0 and adds each argument to the running total. (JS exercise 13)

JavaScript

The constructor takes name and assigns it to the new instance’s name property via this. (JS exercise 14)

JavaScript

29. Create canLogIn as a constant that is true only when username and password are both not equal to the empty string. Use !== and &&.

Each !== test checks one field against an empty string. && requires both tests to be true. (JS exercise 17)

JavaScript

30. Assume user exists but user.address may be missing. Create city from user.address.city using optional chaining and the nullish fallback "Unknown".

?. safely reads city if the address exists. ?? supplies the fallback when the result is null or undefined. (JS exercise 18)

JavaScript

CSS
