# Exams project

Use this default layout for HTML reviewers in this project unless the user requests a different format.

- Put every question on one compact, scrollable page. Use two columns on wider screens and one column on narrow screens.
- Give each question its own **Check answer** button. Show its result and explanation directly under that question.
- Every answer must can be checked even if the input is blank.
- Always save the HTML file created in this folder and rename it to this format (Subject.html).
- Add a button for summary of correct and wrong answers.
